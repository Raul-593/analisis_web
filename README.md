# Web Análisis Python - Champions League

Proyecto en su **versión 1** desarrollado con Python y [Reflex](https://reflex.dev).

## Objetivo

Esta versión tiene un único propósito: **mostrar la tabla de posiciones de la UEFA Champions League**.

La aplicación consulta los datos de los equipos y presenta la clasificación actualizada de forma sencilla y visual.

## Características (v1)

- Visualización de la tabla de posiciones de la Champions League.
- Interfaz web construida con Reflex.
- Datos de equipos, puntos y clasificación.
